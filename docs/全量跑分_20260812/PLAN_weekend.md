# 周末全量测试计划（判据全部预先写死）

## 为什么是这个设计

本轮所有历史结论的共同软肋：**噪声标尺都不是同时段测的**。
§三十四 已写明"噪声标尺要和被测对象同条件、同时段"，但此后仍反复引用别时段的 ±3，
Codex 对此的批评成立。有整段独占机器的时间，就把这一条补上。

**A1 → B → A2**：两个空跑臂把实验臂夹在中间。

- `A1 vs A2` = 同时段、同构建、同题的真实噪声（也能暴露时间漂移）
- `B` 相对两个空跑臂的净值，才有资格谈"超不超噪声"
- 若 `A1 vs A2` 本身差异就大，说明这台机器当晚不稳定，**B 的任何结论都不成立**，如实报告

## 判据（跑之前写死，跑完不许改）

净值 =（少的编造）×2 +（多的命中），复合键 `(book, question)`。

1. **先看噪声**：令 `N = |A1 vs A2 的净值|`。
2. **采纳 B 为默认**，当且仅当：
   - `B 相对 A1 的净值 > 3N` **且** `B 相对 A2 的净值 > 3N`（两个空跑臂都要过），
   - **且** 编造绝对条数增加 ≤ 5，
   - **且** 中文四本的库外拒答仍为 40/40、编造 0。
3. 任一条不满足 → 维持默认关闭，如实写明差在哪一条。

**第 2 条里的"编造条数上限"是独立否决项**：净值划算不足以采纳，
因为词形碰撞型编造对本项目的定位伤害不是净值口径能表达的（§三十六/§四十三 的教训）。
