误报排除：`deploy_pack/*` 三处改动写入时间是 **8/5**，比这轮早 9 天，不是它动的。

### 它找到的两个真 BUG（都是我漏掉的）

1. **EPUB 引用令牌含中文长标题**。`loc` 整串（`ch3:1 银币诞生于美索不达米亚`）
   当引用令牌，模型必须逐字复制中文标题，差一个字就被判伪造引用、**整个答案换成拒答**。
   修法是只取稳定的小节号 `ch3:1`。
   **我自己 §三十七 的探针输出里就印着这种长标题引用，我没看出脆弱性。**

2. **同标签的多个块被后块丢弃**。引用令牌缩短后，同一章节的块必然共用标签；
   若仍按旧逻辑只留第一块，接地率就算不到模型实际看过的证据。
   Codex 改成**追加**块文本而非丢弃，与第 1 条成对修复。工程上是对的。

这两条正是我 §三十七 卡住的地方——我排除了检索、闸门、接地率阈值三项后停在
"模型侧与裁剪未分离"，**真正的原因是第三条我没想到的：引用校验因标题不匹配而误杀。**

### 它找到我的一个真 BUG

跑分对照用 `question` 当配对键，而 1007 行里有 **16 组跨书复用的库外探针、共 35 行**
被静默覆盖，所有对照实际只比了 972 道。正确的键是 `(book, question)`。

**但独立复核后：这个错不改变任何结论。** 六个臂用两种键算出的净值完全相同
（+3 / −3 / −7 / −14 / −1 / +36）——那 35 行两臂都正确拒答，对差值贡献为零。

## 三、我自己被推翻的一个结论（§三十六 → §四十三）

§三十六 写着「混合的词形碰撞编造，没有基于距离的便宜修法」。**这句话是错的。**

错因不在数据，在**机制建模**：我当时算的是「闸门拦下 → 变成过度拒答」，
于是把 444 道两臂都命中的题算进误伤；而实现的机制是
「拦下 → 退回纯向量结果」，那些题退回后仍是命中，**零损失**。

按正确语义我独立复算（未复用他人代码）：

```
阈值 0.99   命中 +48   编造 +2   净值 +44
纯混合      命中 +48   编造 +6   净值 +36
```

且 0.99 不是新调参，就是既有的 `_EVIDENCE_FLOOR`。
Codex 用的是**按教材留一法**（+40），比我随机半分（+36）更严谨——随机分割会让同书的题泄漏。

**教训**：量一个改动之前，先写出它落地后的伪代码，确认测量模型与它逐行对应。
量错对象比不量更危险，因为会给出一个看起来严谨的错误结论。
