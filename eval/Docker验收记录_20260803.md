## 发现并修复的问题

1. `.dockerignore` 的 `agent_*/` 规则误排除了 `code/agent_runtime.py`，导致首轮容器测试收集失败；已增加精确反排除规则。
2. `deploy.ps1` 使用无 BOM UTF-8 中文时，被 Windows PowerShell 5.1 按 ANSI 解码并破坏语法；已把脚本文案改为纯 ASCII，原样重跑通过。
3. SVG 不能直接作为 Ollama `images` 输入；当前实现使用 PyMuPDF 本地光栅化为 PNG，真实 VL 链路和自动化回归测试均通过。
4. `requirements.txt` 原为宽松下限，可能因上游升级漂移；已锁定到本次成功构建并通过 50 项测试的直接依赖版本。

- 本次 SVG/VL 是真实功能冒烟，不是多本图表/公式准确率评测。

- Web UI 使用 FastAPI 测试客户端时有一条弃用提醒；服务接口本身通过，后续可升级测试适配器消除提醒。
